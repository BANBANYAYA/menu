Duck Bakery 菜单

双击 index.html 可在本机查看，发布时保留文件夹结构。

商品与价格：
- js/products.js 维护商品和 variants 规格。
- 每个规格的 priceCents 以分为单位：1400 表示 $14.00。
- 250g、450g 和组合装分别维护价格；已使用的商品 id、规格 id 请保持不变。
- 隐藏商品可以保留为注释，不会出现在菜单中。

图片：
- images-styled 保存原图，optimized 保存适合手机和电脑的轻量图片。
- js/images.js 记录各尺寸图片；新图片没有优化版本时，会直接显示原图。

购物袋：
- 自动保存在当前浏览器，按商品和规格分别计数。
- 旧购物袋会保留；多规格商品需补选规格后才能核对合计和复制清单。
- 复制清单包含名称、规格、数量、单价、小计与商品合计。
